# V0.3 活动复盘实施与验收

目标：活动数据 → 人工观察 → 模板草稿 → 人工编辑 → 保存 / Markdown 导出。依据用户本次完整 V0.3 规格直接执行，不接外部模型 API，不改变 V0.1 / V0.2 业务规则和视觉。当前稳定提交 9eaed15，原有 27 项测试通过。

模块：review_generator.summarize_review(data) 复用 metrics，输出报名/到场身份、渠道与极值（支持并列、排除零报名渠道）、前三方向、明确价值跟进状态；generate_review(data, observations) 输出固定五章，标注数据事实与人工观察，不读取姓名/备注/动作等个人字段。review_store.ReviewStore 管理 UTF-8 Markdown、内容版本、原子保存与友好错误。review_page.render_review_page(data, revision, source) 管理 Streamlit 三个区域和会话状态；app.py 仅增加导航及调用。

草稿首次进入页面从 data/event_review_draft.md 加载；页面切换保留会话草稿及人工输入；刷新/重启恢复已保存正文。重新生成任何非空草稿均须确认，只替换编辑区，保存才更新磁盘。导出和文本选择复制均基于当前编辑区。人工观察仅保存在会话中，正式保存正文包含所用人工观察；原始/working CSV 不接收复盘输入。本地草稿 Git 忽略。
