# 科技创业活动观察与跟进助手 V0.1 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将现有合成活动数据变为可在本地运行的三个只读页面。

**Architecture:** app.py 负责导航与展示；data_loader.py 读取并验证 CSV；metrics.py 负责 KPI、图表汇总、价值筛选及排序；visualizations.py 只接收汇总表并创建 Plotly 图。

**Tech Stack:** Python、Pandas、Plotly、Streamlit；标准库 unittest 与 Streamlit AppTest 验证。

**Spec:** 用户本轮完整 V0.1 需求及 data/DATA_DICTIONARY.md。

## Global Constraints

- 不修改现有模拟 CSV 或数据字典；基线 CSV SHA256：6BAE9989B305C488EECD303CBC7776B3A11D60E7B7FF6F1AB127F4EEB9CEA7E3。
- 不接 API、不做数据库、登录、RAG、Agent、Docker 或持久化编辑，不推送 GitHub。
- 三个页面：活动总览、活动观察、关系跟进。明确标注 Synthetic Demo Data。
- KPI 与分析汇总不能写死。价值定义沿用字典中四种明确意向，并要求到场。
- 身份和方向图统计全部报名者；渠道分母为该渠道报名人数；所有口径在页面标注。
- 跟进顺序：待跟进、已初步建联、跟进中、已完成对接；三类筛选取交集。

## Review Focus

- 无文件、错误编码、缺字段、重复编号、无数据：给出中文错误，不显示错误 KPI。
- 非法枚举或未到场却已对接：拒绝载入并指出问题所在行。
- 空机构和备注允许保留；空负责人须能单独筛选已完成记录。
- 空筛选组合显示说明；切换页面后不应出现异常。
- 图表百分比与人数使用明确的不同坐标轴，显示 0%–100% 到场率。
