# 创业者交流 — Synthetic Demo Data

本数据集为 **Synthetic Demo Data（合成演示数据）**，用于「科技创业活动观察与跟进助手」后续 Dashboard、活动复盘与跟进功能测试。不是实际报名、签到或业务成果，不可用于推断真实活动表现。

姓名、公司、项目、机构均为人工组合的虚构内容，不引用或影射真实人物、公众人物或公司；如有同名，纯属巧合。景川、小林、Mia 是指定的演示负责人标签，不代表实际分工。

## 文件与读取约定

- 文件：`data/demo_tech_event.csv`。活动名称为「创业者交流」，本文件仅包含这一场模拟活动。
- 100 条报名记录，每行代表一位报名者；13 个字段，首行为字段名，没有说明行或汇总行。
- 编码为 UTF-8 with BOM，便于 Excel 识别中文。程序读取建议使用 `utf-8-sig`，避免将 BOM 误认为字段名的一部分。
- 使用英文逗号分隔，字段以双引号包围。空值为 CSV 空字符串，不使用「空值」「NULL」等文字占位。
- 非空 `notes` 均以 `Synthetic Demo Data；` 开头，机构名称以 `虚构·` 开头。保留这些标识，避免将演示数据误认为真实数据。
- 编号仅用于唯一识别，不表示报名先后、价值排序或时间顺序。本数据不包含日期，不能用于测试时间趋势。

## 字段定义

| 字段 | 含义 | 允许值或格式 | 是否允许为空 |
| --- | --- | --- | --- |
| attendee_id | 报名者唯一编号 | 本数据为 A001–A100，格式为 A 加三位数字，不能重复 | 否 |
| name | 虚构中文姓名 | 中文文本，不对应真实人员资料 | 否 |
| role | 报名者主要身份 | 创业者、投资人、产业嘉宾、科技从业者、其他 | 否 |
| organization | 虚构公司、创业项目或机构名称 | 以「虚构·」开头的文本；缺失表示未提供 | 是 |
| startup_stage | 创业项目当前阶段 | 想法阶段、MVP、已上线、已有收入、融资中、不适用 | 否 |
| field | 主要关注或创业方向 | AI Agent、企业服务 / SaaS、Robotics、AI 应用、开发者工具、消费科技、其他 | 否 |
| registration_channel | 本次报名归属渠道 | 社群、朋友推荐、公众号、小红书、合作机构 | 否 |
| attended | 是否实际到场 | 是、否 | 否 |
| connection_intent | 活动结束时的主要对接意向 | 寻找投资、寻找创业者、寻找合作伙伴、行业交流、招聘 / 人才、暂无明确需求、未到场 | 否 |
| followup_status | 当前对接进度 | 待跟进、已初步建联、跟进中、已完成对接、暂不跟进、未到场 | 否 |
| followup_owner | 当前需要执行下一步动作的负责人 | 景川、小林、Mia，或空字符串 | 是 |
| next_action | 当前下一步动作 | 简短动作文本，如添加微信并了解融资阶段、介绍相关创业者、补充项目资料、约下一次线上沟通；无待办为「暂无」，未到场为「未到场」 | 否 |
| notes | 简短现场或跟进备注 | 非空时以「Synthetic Demo Data；」开头；缺失不等于没有到场 | 是 |

`role`、`field`、`registration_channel`、`connection_intent` 均为单选，不应按多选拆分。枚举值及其空格应保持原样，例如 `企业服务 / SaaS` 和 `招聘 / 人才`。

## 状态与业务逻辑

- 创业者填写五种具体项目阶段；本版本所有非创业者均填写「不适用」。阶段为单选，「融资中」表示以当前融资状态作为主要标签，不同时编码产品成熟度。
- 未到场者的 `connection_intent`、`followup_status`、`next_action` 均为「未到场」，`followup_owner` 为空，没有现场对接结论。
- 「待跟进」表示已识别具体需求，但尚未开始会后联系；「已初步建联」表示已开始联系；「跟进中」表示正在推进具体沟通或资料匹配。这三类均有负责人和明确下一步动作。
- 「已完成对接」仅代表介绍或对接动作已完成，不表示融资、合作或招聘成交。本版本这类记录无剩余任务，下一步为「暂无」，当前负责人为空；历史负责人不在本数据范围内。
- 「暂不跟进」仅用于到场但以行业交流或旁听了解为主的人，下一步为「暂无」，负责人为空。
- 寻找投资只分配给已上线、已有收入或融资中的创业者；寻找创业者只分配给投资人。合作需求分布于创业者、产业嘉宾和科技从业者。
- 指定负责人按需求分工：景川负责投资与创业者匹配，小林负责合作，Mia 负责招聘；不需要跟进或未到场者不分配负责人。

## 统计口径与设计结果

这些分布由固定配额和角色相关规则构造，顺序打散，不是各字段独立随机抽样，也不代表真实世界的渠道效果。

- 报名人数：所有数据行，共 100 人。
- 到场人数：`attended = 是`，共 71 人；到场率 = 到场人数 / 报名人数 = 71.0%。
- **明确后续对接价值**：到场且 `connection_intent` 属于「寻找投资、寻找创业者、寻找合作伙伴、招聘 / 人才」，共 22 人，占到场者 31.0%。这是演示统计定义，不是客观价值评分。
- 22 人包含待跟进 13 人、已初步建联 4 人、跟进中 3 人、已完成对接 2 人。当前仍需执行动作的为前面三类，共 20 人；与「有对接价值」人数分开统计。
- 其他到场者 49 人为「暂不跟进」，未到场者 29 人。
- 跟进清单可筛选 `followup_status = 待跟进`；所有未完成任务可筛选「待跟进、已初步建联、跟进中」。

## 使用与维护

后续加入真实数据时，应将其与本演示文件分开保存，并在页面或报告中继续清晰显示数据来源。修改演示数据后，重新核对唯一编号、允许值、人数与比例、未到场一致性、跟进动作与负责人，以及以上统计说明。
